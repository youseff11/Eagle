# Eagle Dashboard — dependencies

# Django is the ONLY third-party package. Everything else runs on the Python
# standard library on purpose:
#   WhatsApp Cloud API  -> urllib          (dashboard/whatsapp.py)
#   Claude API          -> urllib          (dashboard/ai.py)
#   Incoming e-mail     -> imaplib, email  (management/commands/fetch_emails.py)
#   Outgoing e-mail     -> django.core.mail over SMTP (dashboard/mailer.py)
#   .docx text extract  -> zipfile         (dashboard/ai.py)
#   Webhook signatures  -> hmac, hashlib   (dashboard/whatsapp.py)
#
# Install:  pip install -r requirements.txt
# =============================================================================
