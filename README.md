# Eagle Dashboard — Phase 1

داشبورد شركة **Eagle** للترجمة. Django app واحد اسمه `dashboard` + فولدر `templates` واحد جوّه فولدرات.
دارك/لايت مود، وترجمة عربي/إنجليزي متخزّنة جوّه الـ HTML نفسه (`data-ar` / `data-en`) وبتتبدّل من الزراير من غير refresh.

---

## المتطلبات

**Django بس.** كل الباقي مكتبات بايثون الأساسية — مفيش `requests` ولا `celery` ولا `redis`.

```bash
python -m venv .venv
.venv\Scripts\activate          # ويندوز
pip install -r requirements.txt
```

## الفلو زي ما هو متنفّذ

1. **رسايل العملاء** بتدخل من واتساب أو إيميل على `/webhooks/whatsapp/` و `/webhooks/email/`.
   الأوبريشن بيشوف **كود العميل بس** (`CL-0003`) — الاسم والتليفون والإيميل للأدمن لوحده.
   أي رسالة فيها كلمة `rate` / `ريت` / `سعر` بتتحجب عن الأوبريشن تمامًا وتظهر للأدمن بس.
   الكلمات دي تتغير من `/panel/settings/`.
2. **الأوبريشن يعمل Claim** للرسالة (زرار «استلمت الرسالة») وبعدين يحوّلها لتاسك.
3. كل **تيم ليدر** تحته فريق مترجمين (`team_lead` في بروفايل المترجم).
4. صفحة `/ops/team/` بتوّري لكل تيم ليدر: نشط ولا أوفلاين **حسب الشيفت**، وكام واحد فاضي/مشغول/أوفلاين
   في فريقه، والتاسك الحالية لكل مترجم.
5. الأوبريشن يعمل **assign** لتيم ليدر → التيم ليدر بيجيله **پوب أپ بعداد 60 ثانية + صوت تحذير**.
6. لو عمل Accept: بيتفتح **شات (أوبريشن + تيم ليدر)** جوّه السيستم بيتبعت فيه الملفات والرسايل.
   لو مردّش في 60 ث: **يتخصم 1/8 نجمة** من الـ 5، والتاسك ترجع للأوبريشن مع تنبيه بصوت إنه يعمل assign لحد تاني.
7. **متطلبات العميل** (بيحب / بيكره / قاعدة) يقدر يضيفها الأوبريشن والتيم ليدر والأدمن،
   وبتظهر جنب التاسك وفي صفحة `/clients/<code>/`. المترجم بيقراها بس.
8. التيم ليدر يعمل **assign لمترجم من فريقه** → نفس عداد الـ 60 ثانية ونفس الخصم لو مردّش،
   ويرجع للتيم ليدر يعيد التوزيع.
9. أول ما المترجم يقبل بيتعمل **جروب شات تلقائي**: أوبريشن + تيم ليدر + مترجم، وفيه الملفات.
10. **الديدلاين** بيحطه الأوبريشن (من العميل)، وبيظهر للمترجم، وبيتبعتله **تحذير قبله بـ 15 دقيقة**
    (بصوت) + تحذير تاني لو الديدلاين عدّى.
11. المترجم عنده زرار **🔍 تشيك** بيراجع الترجمة بـ Claude API: بيقوله **الأخطاء ومكانها بس ومش بيعدّل**.
    الأدمن هو اللي بيفعّله أو بيقفله من `/panel/settings/`.
    بعدها بيبعت الملفات في الشات → التيم ليدر يراجع → يدوس **✅ تمت المراجعة**
    → الأوبريشن يقدر يدوس **📤 تم التسليم للعميل**.

## ربط واتساب و جيميل

كل الربط من `/panel/settings/` — **مفيش كود يتغير ولا سيرفر يترستارت**.
وفيه زرار **اختبار الاتصال** لكل واحد فيهم بيقولك بالظبط إيه اللي ناقص.

### واتساب (Meta Cloud API)

**1. رابط عام.** الموقع لازم يكون على HTTPS يقدر Meta توصله. للتجربة المحلية:
```bash
ngrok http 8000
```
لو الرابط في صفحة الإعدادات لسه `127.0.0.1` هتلاقي تحذير أحمر — ده معناه إن Meta مش هتوصلك.

**2. في `/panel/settings/`** املا:

| الخانة | من فين |
|---|---|
| Verify token | أي كلمة من اختيارك — بس اكتب نفسها في Meta |
| Phone number ID | Meta → WhatsApp → API Setup |
| Access token | نفس الصفحة (اعمل Permanent token من System User للإنتاج) |
| App secret | Meta → App Settings → Basic (اختياري — بيتحقق من توقيع الرسايل) |

**3. في Meta → WhatsApp → Configuration:**

- Callback URL: `https://<رابطك>/webhooks/whatsapp/` (انسخه من صفحة الإعدادات)
- Verify token: نفس اللي كتبته
- دوس **Verify and Save** بعدين اشترك في حدث **messages**

**4. دوس «اختبار الاتصال»** في صفحة الإعدادات. لو ظهر اسم ورقم الشركة يبقى تمام.

بعد كده الرسايل **والملفات** بتدخل الإنبوكس أوتوماتيك.

> **مهم:** واتساب بيسمح تبعت للعميل رسالة حرة في **24 ساعة** بس من آخر رسالة منه.
> بعد كده لازم Message Template معتمد. السيستم بيقولك ده بوضوح لو حصل.

### إيميل (استقبال IMAP + إرسال SMTP)

جيميل محتاج **App Password** (مش الباسورد العادي) — فعّل 2-Step Verification الأول.

- **الاستقبال:** `imap.gmail.com` : `993` — وشغّل `python manage.py fetch_emails`
  (حطه في Task Scheduler كل 5 دقايق).
- **الإرسال:** سيب خانات SMTP فاضية وهياخد نفس بيانات الـ IMAP، أو املا
  `smtp.gmail.com` : `587` مع TLS.

## تسليم الملفات للعميل

لما التيم ليدر يدوس «تمت المراجعة»، الأوبريشن بيظهرله في صفحة التاسك:

- قايمة بكل ملفات الشات، وملفات المترجم **متعلّمة تلقائي**
- خانة رسالة للعميل
- زرار **«ابعت للعميل وسلّم»** — بيبعت على **نفس القناة اللي العميل كلمنا منها**
  (واتساب أو إيميل) وبعدين يقفل التاسك
- زرار **«قفل من غير إرسال»** لو هتبعت بنفسك

لو الإرسال فشل، **التاسك ما بتتقفلش** وبيظهر سبب الفشل بالعربي عشان تعيد المحاولة.
كل محاولة بتتسجل في «سجل التسليم» جوّه التاسك.

## المهمات الدورية

الـ browser بيعمل heartbeat كل 3 ثواني وبينفّذ القواعد لوحده.
عشان القواعد تشتغل حتى لو محدش فاتح الموقع، فيه اختيارين:

**الأفضل — عفريت واحد بيعمل كل حاجة:**
```bash
python manage.py run_worker
```
بيشتغل للأبد: بيصفّي التأكيدات اللي فات وقتها، بيبعت تحذيرات الديدلاين، وبيسحب الإيميل.
على PythonAnywhere حطه في **Always-on task** (حسابات مدفوعة).

**أو أوامر منفصلة** لو بتستخدم cron / Task Scheduler:
```bash
python manage.py sweep          # كل دقيقة
python manage.py fetch_emails   # كل 5 دقايق
```

> **مهم على PythonAnywhere:** الـ Scheduled tasks أقل تكرار فيها **كل ساعة** —
> وده بطيء جدًا على مهلة الـ 60 ثانية. استخدم **Always-on task** مع `run_worker`.

## بيئتين بنفس الكود

المشروع بيقرا الإعدادات من متغيرات البيئة (أو ملف `.env` جنب `manage.py`).
**مفيش ملف settings تاني ولا كود بيتغير:**

| | محلي (فاضي) | سيرفر |
|---|---|---|
| الداتابيز | SQLite | PostgreSQL لو `DATABASE_URL` متحطة |
| الملفات | مجلد `media/` | Bunny.net لو الـ `BUNNY_*` متحطة |

يعني تسيب `.env` فاضي على جهازك وكل حاجة تفضل زي ما هي.

**Neon (PostgreSQL):**
```
DATABASE_URL=postgresql://user:pass@host.neon.tech/dbname?sslmode=require
```
الـ parser بيمرّر `sslmode` و `channel_binding` وأي باراميتر تاني من الرابط،
وبيشغّل `CONN_MAX_AGE=60` مع health checks عشان اتصال مقطوع ميطلعش 500.
محتاج `psycopg` (موجود في `requirements.txt`).

**Bunny.net (ملفات العملاء):**
```
BUNNY_STORAGE_ZONE_NAME=eagle-storage
BUNNY_API_KEY=<باسورد الـ Storage Zone مش مفتاح الحساب>
BUNNY_REGION=de
BUNNY_CDN_URL=https://yourzone.b-cdn.net
```
لازم **الثلاثة** (zone + key + cdn url) يتحطوا مع بعض، وإلا بيرجع للمجلد المحلي.
كل ملف بياخد لاحقة عشوائية عشان ملفين بنفس الاسم في نفس الشهر ميدهسوش بعض.

> **تنبيه خصوصية:** أي حد معاه لينك الـ CDN يقدر يفتح الملف — ودي مستندات عملاء.
> فعّل **Token Authentication** على الـ Pull Zone من لوحة Bunny، أو سيب الملفات محلية.

**فحص كل حاجة مرة واحدة:**
```bash
python manage.py check_setup           # داتابيز + تخزين + واتساب + إيميل
python manage.py check_setup --write   # وكمان يرفع ويمسح ملف تجربة على Bunny
```

## النشر على PythonAnywhere

بعد رفع الكود وتشغيل `migrate`:

**1. متغيرات البيئة** (تبويب Web → Environment variables، أو ملف `.env`):
```
EAGLE_DEBUG        = 0
EAGLE_HOSTS        = yourname.pythonanywhere.com
EAGLE_CSRF_ORIGINS = https://yourname.pythonanywhere.com
EAGLE_SECRET_KEY   = <مفتاح جديد>
```
لو الحساب **مجاني** ضيف كمان:
```
EAGLE_HTTPS_PROXY  = http://proxy.server:3128
```

**2. الملفات الثابتة** — مع `EAGLE_DEBUG=0` جانغو بيبطل يقدّمها:
```bash
python manage.py collectstatic
```
وفي تبويب Web → Static files:

| URL | Directory |
|---|---|
| `/static/` | `/home/<user>/<project>/staticfiles` |
| `/media/` | `/home/<user>/<project>/media` |

من غير الخطوة دي الموقع هيبقى من غير تنسيق والملفات مش هتتفتح.

**3. Always-on task:** `python /home/<user>/<project>/manage.py run_worker`

**4. اعمل Reload** بعد أي تغيير.

### حساب مجاني ولا مدفوع؟

الحسابات المجانية بتطلع على النت من خلال بروكسي بقايمة مواقع مسموحة بس:

| | مجاني | مدفوع |
|---|---|---|
| استقبال رسايل الواتساب | ✅ | ✅ |
| إرسال للعميل | ✅ (بالبروكسي) | ✅ |
| تنزيل مرفقات العميل | ❌ `lookaside.fbsbx.com` مش مسموح | ✅ |
| جيميل IMAP/SMTP | ❌ مش HTTP أصلاً | ✅ |
| مراجعة الـ AI | ❌ `api.anthropic.com` مش مسموح | ✅ |
| Always-on task | ❌ | ✅ |

بعد ما تشترك، ادخل `/panel/settings/` ودوس **«اختبار الاتصال»** لواتساب وللإيميل —
هيقولك في ثواني إذا كان كل حاجة شغالة.
